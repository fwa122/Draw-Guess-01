## 测试步骤

### 第一步：启动服务器

1. 打开终端，进入项目根目录
```bash
cd d:\xiangmujianli
node server/server.js
```

2. 确认服务器输出：
```
服务器运行在 http://localhost:3000
局域网访问地址: http://192.168.1.xxx:3000
```

### 第二步：在 HBuilderX 中运行项目

1. 打开 HBuilderX
2. 导入项目：`d:\xiangmujianli\APP\你画我猜`
3. 运行到浏览器（或手机）：
   - 点击工具栏的"运行"
   - 选择"运行到浏览器" → "Chrome"

### 第三步：测试连接

1. 应用启动后，会自动打开测试页面
2. 在"服务器地址"输入框中输入：
   - 本机测试：`http://localhost:3000`
   - 局域网测试：`http://192.168.1.xxx:3000`（替换为实际 IP）

3. 点击"连接"按钮
4. 观察日志区域：
   - **成功**: 显示 "连接成功！"
   - **失败**: 显示错误信息

### 第四步：测试功能

#### 4.1 获取房间列表
- 点击"获取房间列表"按钮
- 日志应显示：`收到房间列表: [...]`

#### 4.2 创建测试房间
- 点击"创建测试房间"按钮
- 日志应显示：`发送创建房间请求: ...`
- 服务器终端应显示：`房间创建: XXXX by 测试玩家`

#### 4.3 自定义事件测试
- 事件名：输入 `getRooms`
- 数据：输入 `{}` 或留空
- 点击"发送测试消息"

### 失败排查

#### 问题1：连接超时
```
连接失败: {"errMsg":"connectSocket:fail"}
```
**解决方案**：
- 检查服务器是否启动
- 检查 IP 地址是否正确
- 检查防火墙是否阻止端口 3000

#### 问题2：协议错误
```
消息解析失败: ...
```
**解决方案**：
- 检查服务器 Socket.io 版本（需要 4.x）
- 查看服务器日志确认消息格式

#### 问题3：频繁断线
```
服务器断开连接
```
**解决方案**：
- 检查网络稳定性
- 查看服务器日志是否有错误

## 技术说明

### Socket.io 协议格式
```
发送格式: 42["event",{"data":"..."}]
接收格式: 42["event",{"data":"..."}]

心跳包:
- Ping: 2
- Pong: 3
```

### uni-app x WebSocket API
```typescript
// 连接
uni.connectSocket({
  url: 'ws://localhost:3000/socket.io/?EIO=4&transport=websocket',
  success: () => {},
  fail: (err) => {}
})

// 发送
socketTask.send({ data: '42["event",{}]' })

// 接收
socketTask.onMessage((res) => {
  console.log(res.data)
})
```

## 常见问题

### Q1: 为什么不用 socket.io-client.js？
**A**: uni-app x 对 JavaScript 库的支持有限制，使用原生 API 更稳定可靠。

### Q2: 如何在真机上测试？
**A**: 
1. 手机连接同一局域网
2. 输入电脑的局域网 IP（如 `http://192.168.1.100:3000`）
3. 确保电脑防火墙允许 3000 端口

### Q3: 如何调试？
**A**: 
- 浏览器：按 F12 打开开发者工具
- 手机：使用 vConsole 或日志页面
