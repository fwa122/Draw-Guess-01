# 🎨 你画我猜 - 多人实时在线游戏

一个基于 WebSocket 的实时多人在线你画我猜游戏项目,支持多人同时游玩,实时同步绘画内容。

## 📖 项目简介

这是一个完整的多人在线你画我猜游戏系统,采用前后端分离架构,使用 Socket.IO 实现实时通信。玩家可以在游戏中轮流绘画和竞猜,通过实时同步的 Canvas 画板进行互动。

### 安装依赖

```bash
cd server
npm install
```

### 启动服务器

```bash
npm start
```

服务器启动后会显示:
```

局域网访问地址: http://192.168.x.x:3000
```

### 访问游戏

打开浏览器访问 `http://localhost:3000` 即可开始游玩。

## 🎮 游戏玩法

1. **创建房间**: 设置房间名称、人数、回合时间等参数
2. **玩家准备**: 所有玩家点击"准备"按钮
3. **开始游戏**: 房主点击"开始游戏"
4. **轮流绘画**: 按座位顺序轮流绘画,绘画者看到词汇并绘画
5. **竞猜答案**: 其他玩家通过聊天输入答案竞猜
6. **计分排名**: 根据答对顺序获得梯度分数
7. **游戏结束**: 所有回合结束后显示最终排名

## 🎯 技术亮点详解

### 1. 服务端权威计时器
服务端统一管理回合时间,每秒广播剩余时间到所有客户端,防止客户端篡改计时器作弊。

### 2. 状态机校验机制
客户端和服务端双重状态校验,确保页面流转符合游戏规则,防止非法跳转。

### 3. Canvas限频优化
绘画事件限制在30ms间隔发送,避免高频事件导致网络拥堵,保证多人游戏流畅性。

### 4. 掉线重连处理
60秒缓冲期允许玩家重连,socket.id迁移、分数保留、状态同步等完整处理机制。

### 5. 梯度计分系统
第1名10分,第2名8分,第3名6分...公平激励快速答对的玩家,绘画者获得额外奖励。
